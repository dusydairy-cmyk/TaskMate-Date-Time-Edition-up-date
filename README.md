# TaskMate — Student To-Do List Manager

A responsive, browser-based student task planner. Add tasks with a **specific due date and time**, set priorities, optionally add a subject/category, and track completion.

## Features
- Task title, due date, and exact due time
- High, medium, and low priorities
- Optional subject/category
- Upcoming, overdue, completed, and all-task filters
- Sort by due date, priority, or recently added
- Mark tasks complete, edit tasks, or delete tasks
- Saves tasks in the browser using localStorage
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this project.
2. Open `index.html` in a modern browser.

No build tools or server are required.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of your repository's `main` branch.
2. Open **Settings → Pages** in your repository.
3. Set the source to **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. After deployment, open the URL shown by GitHub Pages.

## Note
Tasks are stored in the browser on the current device. They do not automatically sync between browsers or devices.
